# Katalog Requirement Kepatuhan

Rujukan ID PRV/SEC/UX yang berlaku berada di [01-compliance/requirements-catalog.md](../01-compliance/requirements-catalog.md). Enam register R1–R6 memakai ID yang sama dari katalog tersebut.

Sinkronisasi main menyatukan dua katalog yang sebelumnya memakai ID sama dengan arti berbeda. Jangan menerbitkan ulang ID lama untuk persetujuan, retensi, antrean, atau backup; rujuk deskripsi pada katalog utama. Kebutuhan layanan tetap dikembangkan melalui [use cases](use-cases.md) dan SRS M02. Retensi operasional menunggu keputusan klinik; angka dua tahun pada rancangan lama bukan kebijakan yang disetujui.
