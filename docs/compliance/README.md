# Dokumen kepatuhan

Enam register dan katalog requirement berada di [docs/01-compliance](../01-compliance/) sesuai template dosen. Gunakan dokumen di sana sebagai rujukan data, status kontrol, dan ID PRV/SEC/UX.

Folder `evidence/` di sini menyimpan bukti historis dari main sebelum sinkronisasi branch. Bukti pemeriksaan versi branch terbaru berada di [01-compliance/evidence](../01-compliance/evidence/README.md); hasil lama tidak membuktikan artefak APK terbaru.
